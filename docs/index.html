Hands-free Claude Code.

WHY

flow No alt-tab to approve. Every Claude Code permission prompt usually costs you a context switch — mouse, click, look away from the diff. A gesture keeps your eyes where the work is.
silence Public-space coding. Voice is awkward in a coffee shop. A tiny thumbs-up to the webcam is invisible to everyone except your laptop.
safe Advisory by default. The popup tells you what you signaled and asks you to click in Claude Code yourself. Wiring to a real PreToolUse hook is intentionally opt-in.

RUN IT YOURSELF

# clone + install (one shot)
git clone https://github.com/CasterlyGit/hand-signal.git
cd hand-signal && ./scripts/setup.sh

# try the focused popup
source .venv/bin/activate
handsignal ask "Should Claude run: rm -rf node_modules?"

# or the always-on streaming daemon
handsignal listen --preview
